## 1. Обязательно (без этого покрытие неполное)

- [ ] **Получить бесплатный `TAVILY_API_KEY`**
  1. Зарегистрироваться на https://tavily.com (карта не нужна, 1000 запросов/мес бесплатно).
  2. Скопировать API key.
  3. Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**
     → Name: `TAVILY_API_KEY`, Secret: твой ключ.
  - **Зачем:** без него в облаке не работают (1) поиск новых хакатонов по интернету и (2) путь к Crossweb —
    Cloudflare блокирует серверы GitHub, а Tavily читает Crossweb со своей стороны.
    Сейчас Crossweb обслуживается из статичного снимка от 3 окт. 2026: он **устареет примерно через 8 дней**,
    после чего в репозитории сам откроется issue «Hackathon sources need attention».
  - Расход: ~15 запросов в день ≈ 450 в месяц (лимит 1000).

- [ ] **Получить бесплатный ключ LLM** (чтобы ИИ мог читать даты на найденных страницах)
  1. Самый простой вариант — Google Gemini: https://aistudio.google.com/apikey → Create API key.
  2. Репозиторий → Settings → Secrets and variables → Actions:
     - Secret `LLM_API_KEY` = ключ
     - Secret `LLM_BASE_URL` = `https://generativelanguage.googleapis.com/v1beta/openai`
     - (вкладка **Variables**) Variable `LLM_MODEL` = `gemini-2.5-flash`
  - Без своего ключа workflow пробует бесплатный GitHub Models с встроенным токеном — **я это не смог проверить**,
    поэтому надёжнее завести свой ключ.

- [ ] **После добавления ключей — запустить вручную:** Actions → `update` → **Run workflow**,
  затем на сайте в разделе «Źródła» проверить, что у «Wyszukiwarka + AI» зелёный статус
  и в Crossweb не пишет про устаревший снимок.

## 2. Проверки во времени (я не мог проверить за один сеанс)

- [ ] **Завтра утром:** убедиться, что сработал плановый запуск (cron 05:17 UTC ≈ 07:17 по Кракову):
  Actions → `update` → должна быть запись с типом `schedule`. До сих пор проверены только ручной и push-запуски.
- [ ] **Через неделю:** открыть сайт и убедиться, что число событий растёт/меняется, а раздел «Źródła» без красных точек.
- [ ] Если откроется issue **«Hackathon sources need attention»** — в нём написано, какой источник сломан и почему.
  Оно закрывается само, когда источник снова здоров.

## 4. Известные ограничения (честно)

- Крупнейшие источники для Кракова — польские сайты и сезонные серии; на Devpost/Luma/MLH Краков почти не встречается (~2 события в год).
  Поэтому в списке много «Oczekiwane» — это ожидаемые ежегодные события, у которых ещё нет точной даты.
- События, которые есть только в Facebook/Discord/LinkedIn, автоматически не находятся (запрещено условиями этих сайтов) — только вручную.
- Путь «Tavily → Crossweb → ИИ» и GitHub Models я проверил только на тестах с подставными данными: настоящих ключей у меня нет.
- GitHub предупреждает, что `ubuntu-latest` перейдёт на Ubuntu 26 с 19 окт. 2026 и что Node 20 в actions устаревает — пока на работу не влияет.
- Если репозиторий 60 дней без коммитов, GitHub отключает расписание; здесь workflow сам коммитит данные каждый день, так что этого не случится.
